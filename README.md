# Desafios de Lógica do site BeeCrowd
Este repositório contem o código de solução de desafios do site Beecrowd (https://judge.beecrowd.com/pt/categories). 
Todos solucionados com a linguagem JAVA.
Os desafios foram separados de acordo com a categoria dada no próprio site.

Com esses desafios pude treinar:
- lógica de programação;  
- conceitos básicos da linguagem JAVA, como sintaxe:
  - variáveis
  - operadores
  - estrutura de repetição
  - estrutura condicional
  - estruturas de dados (arrays e matrizes)
- versionamento com git e github;
- uso da IDE IntelliJ.





### Como testar no site

- Copie o código do arquivo da solução escolhida; 
- No editor do site, altere o nome da classe para "Main";
- Clique em Enviar e aguarde.
